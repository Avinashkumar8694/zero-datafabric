controllers/policyController

Access-policy control plane. Policies are engine-agnostic (row predicate + column masking) and enforced by the fabric on non-RLS engines (Mongo/ES/remote), and can also be exercised on SQL engines via the `x-act-as-role` "view as" mechanism.
Description:
  • Access-policy control plane. Policies are engine-agnostic (row predicate + column masking) and enforced by the fabric on non-RLS engines (Mongo/ES/remote), and can also be exercised on SQL engines via the `x-act-as-role` "view as" mechanism.
